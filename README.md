# Online Quiz Application

## 📌 Project Description

Online Quiz Application is a web-based quiz system developed using HTML, CSS, and JavaScript.

Users can enter their name, answer multiple-choice questions, view the timer, and receive their final score and percentage.

## 🚀 Features

- User name input
- Multiple-choice questions
- 15-second timer
- Correct and wrong answer indication
- Progress bar
- Score calculation
- Percentage calculation
- Restart quiz option
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
